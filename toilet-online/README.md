# 변기키우기 온라인 서버 버전

기존 단일 HTML 게임을 보존하면서 Cloudflare Workers, Pages 정적 자산, D1을 한 프로젝트로 묶은 첫 온라인 버전입니다.

## 포함된 기능

- 기존 게임 전체
- 환생 시 주식·부동산·미니게임 상태 초기화 보강
- 반복 구매 가능한 환생 버프 상점(다음 가격 1.6배)
- 삼선 통합 콘텐츠 메뉴
- 32×32 그림 그리기, 유료 저장, 자유 전시
- 경매용 아이템 30종과 햄릿·영지전 저확률 드롭
- 온라인 계정과 친구 코드
- 친구 요청·수락·접속 상태·1:1 메시지 API
- 아이템·그림 경매와 판매자 누진세
- 종합·환생 랭킹 API

## 처음 배포하기

1. 이 폴더 전체를 GitHub 저장소 루트에 업로드합니다.
2. Cloudflare 대시보드에서 D1 데이터베이스 `toilet-online`을 생성합니다.
3. 표시된 D1 Database ID를 `wrangler.jsonc`의 `REPLACE_WITH_D1_DATABASE_ID`와 교체합니다.
4. 터미널에서 `npm install`을 실행합니다.
5. `npm run db:init`으로 표를 생성합니다.
6. `npm run deploy`로 배포합니다.

GitHub 자동 배포를 사용할 때도 빌드 대상은 이 저장소이며 Worker 진입점은 `src/index.js`, 정적 게임 폴더는 `public`입니다.

## 중요한 현재 제한

현재 게임 경제가 원래 브라우저 저장 방식이므로 최초 서버 버전의 자산 동기화는 클라이언트 값을 서버에 반영합니다. 공개 서비스 전에 모든 코인 획득·구매를 서버 판정 방식으로 단계적으로 옮겨야 조작을 완전히 막을 수 있습니다.

실시간 접속 상태는 현재 최근 API 활동 60초 기준입니다. 다음 단계에서 Durable Objects WebSocket을 연결하면 즉시 온라인·오프라인 상태와 실시간 메시지 수신으로 확장할 수 있습니다.
